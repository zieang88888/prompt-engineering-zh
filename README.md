## 📚 目录

### 第一篇：入门篇

#### 1. 为什么你的提示词无效？

最常见的 5 个错误：

1. **太模糊**："帮我写点东西" → AI 不知道写什么
2. **没有上下文**："翻译一下" → 翻成什么语言？什么风格？
3. **没有约束**："写个方案" → 多长？给谁看？什么格式？
4. **没有角色**：AI 不知道以什么身份回答
5. **一次问太多**：多个问题混在一起，AI 顾此失彼

#### 2. 提示词万能公式

**好的提示词 = 角色 + 任务 + 上下文 + 要求 + 输出格式**

```
你是一个[角色]。
请帮我[任务]。
背景信息：[上下文]。
要求：[具体要求]。
输出格式：[格式要求]。
```

举个例子：

❌ 差："帮我写个自我介绍"

✅ 好："你是一个资深的简历顾问。请帮我写一份用于[技术面试]的自我介绍，我是[3 年后端开发经验]的工程师，擅长[Java 和分布式系统]。要求：口语化、突出项目成果、时长 1 分钟（约 200 字）。"

#### 3. 提示词六要素

| 要素 | 说明 | 示例 |
|---|---|---|
| 角色 | 给 AI 设定身份 | "你是一位资深律师" |
| 任务 | 明确要做什么 | "审阅这份合同" |
| 上下文 | 提供背景信息 | "这是租房合同，我租 2 年" |
| 要求 | 约束和期望 | "重点看违约条款" |
| 格式 | 输出的样子 | "分条列出，每条带风险等级" |
| 示例 | 给个参考样本 | "类似这样：XXX" |

### 第二篇：进阶技巧

#### 4. 少样本学习（Few-shot）

给 AI 2-3 个示例，它会照着示例的风格和格式来：

```
把下面的句子改写成小红书风格，参考示例：
示例1："这家店太绝了！" → "救命！这家店也太好拍了吧，姐妹们冲！"
示例2："这个软件很好用" → "挖到宝了！这个软件真的好用到哭😭"
请改写："这个项目文档写得很详细"
```

#### 5. 思维链（Chain of Thought）

让 AI 分步思考，复杂问题答案质量翻倍：

```
请一步一步推理，最后给出结论：
题目：一个农场有 3 只鸡和 2 只兔子，一共多少只脚？
第一步：3 只鸡 × 2 只脚 = 6 只脚
第二步：2 只兔子 × 4 只脚 = 8 只脚
第三步：6 + 8 = 14 只脚
结论：14 只脚
```

#### 6. 角色扮演法

给 AI 设定专家角色，答案专业度立刻提升：

```
你现在是[斯坦福大学经济学教授]，有[20 年研究经验]。
请用[通俗易懂的语言]向我解释[通货膨胀对普通人的影响]。
受众：[完全不懂经济学的普通人]。
```

#### 7. 结构化输出

要求 AI 按固定格式输出，方便直接使用：

```
请把下面信息整理成 JSON 格式：
{"标题": "", "摘要": "", "关键词": [], "建议时长": ""}
原文：XXX
```

#### 8. 迭代优化法

一次不满意就二次追问：

```
第一轮：帮我写个活动文案
第二轮：文案太正式了，改得活泼一点，加表情
第三轮：再短一点，200 字以内，突出"免费"
```

### 第三篇：500+ 实战模板

#### 写作类（60+ 模板）

**公众号文章**
```
你是一个 10 万+ 爆款公众号写手。请写一篇关于[主题]的公众号文章。
要求：
- 标题要吸引人，用数字和悬念（如"3 个方法"）
- 开头 100 字内抓住读者
- 分 3-5 个小节，每节有小标题
- 每节讲一个痛点+一个解决方案
- 结尾引导点赞转发
- 全文 1500 字左右
主题：程序员如何高效学习新技术
```

**小红书笔记**
```
你是一个小红书爆款笔记创作者。请写一篇关于[主题]的小红书笔记。
要求：
- 标题 20 字内，带 emoji 和数字
- 正文口语化，多感叹号
- 分点罗列干货，每点一句
- 结尾加标签（#干货分享 #经验分享）
主题：新手如何入门 Python
```

**短视频脚本**
```
你是一个短视频编剧。请写一个 30 秒的[主题]短视频脚本。
格式：
- 前 3 秒：抓眼球开场
- 中间 20 秒：干货内容（3 个点）
- 结尾 5 秒：引导关注
- 每句标注画面和语气
主题：3 个让你效率翻倍的办公技巧
```

**产品文案**
```
你是一个资深产品文案。请为[产品名]写一段推广文案。
产品：[一款 AI 笔记工具]
卖点：[语音速记、自动总结、多端同步]
受众：[职场白领，经常开会]
要求：突出解决"会议记录太麻烦"的痛点，200 字以内
```

#### 编程类（50+ 模板）

**代码生成**
```
你是一个资深[编程语言]工程师。请帮我实现[功能]。
要求：
- 语言：[Python]
- 功能：[解析 CSV 文件并统计每列平均值]
- 输入：[示例输入]
- 输出：[期望输出]
- 风格：[有注释、有错误处理、符合 PEP8]
```

**代码审查**
```
你是一个资深代码审查专家。请审查下面的代码：
[代码粘贴]
重点检查：
1. 潜在的 bug
2. 安全问题
3. 性能问题
4. 代码规范
请按严重程度排序，并给出修改建议。
```

**Bug 修复**
```
请帮我调试这段代码：
[代码粘贴]
问题现象：[报错信息/错误行为]
我已经尝试过：[已尝试的方案]
请：
1. 分析可能的原因（按可能性排序）
2. 给出修复代码
3. 解释为什么这样修复
```

**SQL 编写**
```
你是一个数据库专家。请根据下面的表结构写 SQL：
表：users(id, name, email, created_at), orders(id, user_id, amount, status)
需求：查询最近 30 天每个用户的订单总额，只显示金额大于 1000 的用户，按金额降序
```

#### 办公类（40+ 模板）

**周报**
```
你是一个职场写作专家。请根据我的工作内容写周报：
本周工作：[内容]
下周计划：[内容]
格式：
- 本周完成（3-5 条，每条一句话带结果）
- 遇到的问题（如有）
- 下周计划（2-3 条）
- 结尾一句话总结
语气：客观、简洁、专业
```

**邮件**
```
你是一个商务写作专家。请帮我写一封[邮件类型：请假邮件]：
背景：[我需要请 3 天假，10 月 20-22 日，因为家里有事]
要求：
- 语气礼貌得体
- 说明请假原因（不用太具体）
- 说明工作交接安排
- 表达感谢
- 中文，150 字以内
```

**会议纪要**
```
你是一个会议记录专家。请把下面的会议内容整理成纪要：
原始记录：[粘贴]
格式：
- 会议主题
- 时间/参会人
- 决议（3-5 条）
- 待办事项（谁+做什么+截止时间）
```

**PPT 大纲**
```
你是一个 PPT 设计专家。请为[主题]设计 PPT 大纲：
主题：AI 如何改变我们的工作方式
受众：公司管理层
页数：10 页
要求：
- 每页一个核心观点
- 结构：引入→现状→案例→方案→展望
- 每页写清标题和要点
```

#### 学习类（30+ 模板）

**知识讲解**
```
你是一个[学科]老师。请用[通俗易懂]的方式给我讲解[概念]：
概念：什么是区块链？
要求：
1. 先用一句话类比说明
2. 再分 3 个要点详细解释
3. 举一个生活中的例子
4. 最后总结核心思想
5. 我完全不懂技术，避免专业术语
```

**英语学习**
```
你是一个英语老师。请帮我：
1. 把下面的中文翻译成英文（自然、地道）：[中文]
2. 解释 2-3 个关键表达为什么这样翻译
3. 给出 2 个同义替换
4. 标出难度等级
```

**考试复习**
```
你是一个考试辅导老师。请针对[科目]帮我出一套练习题：
科目：[数据结构]
范围：[二叉树、图、排序算法]
题型：5 道选择题 + 2 道简答题 + 1 道编程题
难度：中等偏上
附答案和解析
```

## 🔧 高级框架

### 1. CRISPE 框架

```
- Capacity（能力）：你是[角色]，具备[能力]
- Insight（洞察）：背景是[情况]，核心是[洞察]
- Statement（陈述）：任务是[任务]
- Personality（个性）：风格是[风格]
- Experiment（实验）：请给我[数量]个不同方案
```

### 2. RTF 框架

```
- Role（角色）：你是一名[角色]
- Task（任务）：需要完成[任务]
- Format（格式）：输出格式为[格式]
```

### 3. 三步追问法

```
第一步：请你先问我 3 个澄清问题，确保理解我的需求
第二步：根据我的回答，给出方案
第三步：方案中标注哪些地方你还不确定，需要我确认
```
